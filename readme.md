# Age groups and representation

Web scraping, text parsing, analysis and visualisation of population data and representation.

Repository with all code and data: [https://github.com/nikomin/agegroupsAndRepresentation](https://github.com/nikomin/agegroupsAndRepresentation)

## 1. Age structure of the German Parliament


*June 2025*

> **Gen X macht in Deutschland Politik —** Fast die Hälfte des 21. Deutschen Bundestages ist zwischen 45 und 60 Jahren alt, gehört also grob zur Generation X. Die Millenials bilden die zweitgrößte Gruppe. Bei den einzelnen Parteien gibt es Unterschiede: während die einen stärker auf ältere setzen, verlassen sich die anderen stärker auf jüngere. (Details: [Gen X macht in Deutschland Politik.ipynb](<./doc/Gen X macht die Politik/Gen X macht die Politik>))

## 2. Age structure of US congress before 2026-midterms


*October 2026*

> Die amerikanische Bevölkerung ist jünger als die deutsche. Der derzeitige amerikanische Kongress hingegen ist etwa zehn Jahre älter als der deutsche Bundestag und die beiden vertretenen Parteien – Demokraten und Republikaner – unterscheiden sich kaum in ihrer Altersstruktur. (Details: [Amerika ist jünger als Deutschland, seine Volksvertreter sind älter.ipynb](<./doc/Amerika ist jünger als Deutschland, seine Volksvertreter sind älter/Amerika ist jünger als Deutschland, seine Volksvertreter sind älter>))
